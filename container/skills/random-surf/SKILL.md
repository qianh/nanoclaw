# Random Surf 自主探索调度器

检查是否到了探索时间，到了则输出探索话题信号。

## 用法

```bash
random-surf
```

## 输出说明

**未到时间**：无输出，静默退出。

**到了时间**：
```
EXPLORE_NOW
话题:{随机话题}
类型:{话题分类}
下次探索:{时间}（{分钟}分钟后）
```

## 话题库

覆盖五大类 40+ 个深度话题：
- 科技前沿（量子计算、AI、脑机接口、核聚变...）
- 宇宙与自然（黑洞、暗物质、费米悖论...）
- 人文历史（轴心时代、货币演化、古文明...）
- 社会与未来（AI对就业、数字身份、人口老龄化...）
- 科学与哲学（意识本质、时间、自由意志...）

## 调度策略

- 每次探索完成后随机等待 1-6 小时再做下一次
- 失败时 15 分钟后重试
- 调度状态保存在 `/workspace/group/discoveries/exploration_schedule.json`
